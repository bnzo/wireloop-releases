# Loop Ride releases

Downloads of Loop Ride, an indoor cycling game for macOS (Apple silicon). Each [release](https://github.com/bnzo/loop-ride-releases/releases) has the app as a zip, its SHA-256, and `latest.json`, which the game reads to tell you when a new version is out (Loop Ride > Check for Updates…).

To install: download the zip, unzip it, and move **Loop Ride** to Applications. To update: quit Loop Ride and replace it with the new one; your rides and settings are kept.
